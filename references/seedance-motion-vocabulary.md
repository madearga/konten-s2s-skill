# Motion Vocabulary Library — Action / Movement / Rhythm / Beat

**Source:** Composite from `Emily2040/seedance-2.0` v5.5.2 + s2s internal `director-strip-7-track.md` + 19-vocab cinematic composition library.

Use this when you need to describe WHAT IS HAPPENING ON SCREEN — the action, the gesture, the body's relationship to objects, and the rhythm of cuts. Camera language lives in `seedance-camera-language.md`. This file is about MOVEMENT.

---

## Core Principle

> **Action verbs carry more weight than adjectives.** "He slams the phone down" > "He angrily puts the phone away."

State:
1. The body part (hand, fingers, head, shoulders)
2. The verb (grabs, releases, slides, taps, pulls)
3. The speed qualifier (slow, sharp, gentle, sudden)
4. The endpoint state (phone face-down, fingers curled, head turned)

```text
right hand grips phone, lifts, rotates 180° face-down on table, hold 2s
```

## Object Interaction Patterns

### Phone / Screen (most-common in PSA / UGC)

| Action Pattern                                          | Read                          |
|----------------------------------------------------------|-------------------------------|
| `hand lifts phone, screen lights face`                   | Attention, distraction        |
| `thumb scrolls feed, screen content changes`             | Engagement, addiction         |
| `phone placed face-down on table`                        | Rejection, choice             |
| `phone thrown across room`                               | Rage, rejection               |
| `phone placed back in pocket, character exits`           | Decision, departure           |
| `screen glow fades to black as device powers down`       | End of cycle, surrender       |
| `thumb hovers over "post" button, no press`              | Hesitation                    |
| `thumb taps "post", screen flashes, character freezes`   | Commit, consequence           |

### Door / Threshold

| Action Pattern                                          | Read                          |
|----------------------------------------------------------|-------------------------------|
| `hand reaches for doorknob, pauses, withdraws`           | Hesitation                    |
| `door opens slowly, light spills across floor`           | Threshold, transition         |
| `character crosses threshold, door closes behind`        | Commitment                    |
| `hand knocks on door, three beats, no answer`            | Appeal, isolation             |
| `footsteps approach door, character pauses, then walks away` | Withdrawal                |

### Light / Lamp

| Action Pattern                                          | Read                          |
|----------------------------------------------------------|-------------------------------|
| `hand clicks desk lamp off, screen remains only light`   | Isolation, withdrawal         |
| `lamp bulb flickers, dies, room goes dark`               | Failure, collapse             |
| `curtain drawn, room darkens`                            | Choice, withdrawal            |
| `sunlight creeps across wall as time passes`             | Time passage                  |

### Money / Wallet / Phone (harmful behavior PSA pattern)

| Action Pattern                                          | Read                          |
|----------------------------------------------------------|-------------------------------|
| `wallet opens, bills counted, folded, placed in pocket`  | Income, normalcy              |
| `phone screen shows transfer pending, character taps confirm` | Transaction, risk       |
| `wallet opens, empty, character stares inside`           | Loss                           |
| `bills flutter across floor in slow motion`              | Loss, dispersion              |
| `hand places last bill on table, hand trembles`          | Final stake, desperation      |

## Rhythm & Beat Vocabulary

The 7-track director strip uses these RHYTHM verbs. Borrowed from Emily's beat taxonomy.

### RHYTHM Verbs (8 verbs)

| Verb          | Meaning                                              |
|---------------|------------------------------------------------------|
| `hold`        | Static frame, no movement, tension through stillness |
| `pause`       | Brief freeze between actions, breath point           |
| `build`       | Speed + intensity increasing                        |
| `release`     | Sudden release of built tension                      |
| `burst`       | Fast peak action, one-shot spike                     |
| `settle`      | Return to neutral, calm after storm                  |
| `drift`       | Slow continuous motion, no sharp events              |
| `breathe`     | Micro-pause + micro-action, organic                  |

### Block Sizes (3)

| Size        | Duration   | Use                                  |
|-------------|------------|--------------------------------------|
| `micro`     | 0.5-1.5s   | Reaction, beat, transition           |
| `standard`  | 2-4s       | Action, dialogue gesture             |
| `extended`  | 5-8s       | Movement, travel, transformation    |

### Fine-Grain Beat Grid (2-3s segments, validated Jun 2026)

For **scripted comedy, dialogue-heavy content, or multi-character choreography**, default to 2-3s segments instead of 5s. Validated pattern from James Sismanes / @JamesSismanes Brooklyn gelato truck sequence:

```text
0:00–0:03: [action + camera + dialogue line]
0:03–0:05: [reaction + cut + response]
0:05–0:07: [comedic moment / reveal]
0:07–0:09: [re-establish + hold]
0:09–0:11: [next beat]
0:11–0:13: [escalation]
0:13–0:15: [resolution]
```

**When to use 2-3s grid:**
- Comedy timing (every 2-3s = laugh beat)
- Dialogue scenes (speaker cut every 2-3s)
- Quick-reaction choreography (POV + response)
- Animation with character performance (animators think in 2-3s blocks)

**When to stick with 5s grid:**
- Slow cinematic, landscape, contemplative
- Travel / transformation sequences
- Single sustained mood with minimal cuts
- PSA / OAK macro work (validated pattern for competition)

**When to use micro-blocks (sub-1s):**
- Reaction shots within a beat
- Micro-gestures (eye flick, breath, finger twitch)
- Punchline timing
- Beat-sync cuts on music downbeats

### Beat Types (5)

| Beat        | Description                                          |
|-------------|------------------------------------------------------|
| `setup`     | Establish state before action                        |
| `trigger`   | Action begins, momentum starts                       |
| `impact`    | Peak moment, peak energy                             |
| `reaction`  | Subject responds to impact, consequence              |
| `breath`    | Quiet beat, lets viewer absorb                       |

### Escalation Levels (5)

| Level | Energy | Use                                          |
|-------|--------|----------------------------------------------|
| 1     | Still  | Setup, opening hold                         |
| 2     | Drift  | Gentle motion, slow build                   |
| 3     | Build  | Active motion, momentum                     |
| 4     | Burst  | Peak action, climax                         |
| 5     | Rest   | Resolution, settling after peak             |

### Escalation Curves (6)

| Curve         | Shape                                             |
|---------------|---------------------------------------------------|
| `flat`        | Constant energy level                             |
| `linear`      | Even ramp up                                      |
| `ease-in`     | Slow start, accelerating end                     |
| `ease-out`    | Fast start, decelerating end                     |
| `ease-in-out` | Slow → fast → slow                                |
| `stepped`     | Discrete jumps between levels                     |

## Emotional Guidance Phrases

These are READ phrases that pair with motion verbs to communicate intent without naming emotion.

### Valence (positive ↔ negative)

| Direction  | Phrase Pattern                                |
|------------|-----------------------------------------------|
| Positive   | `settles into`, `relaxes into`, `opens to`    |
| Negative   | `curls away from`, `tightens against`, `shrinks from` |
| Neutral    | `holds`, `rests on`, `passes through`          |

### Arousal (calm ↔ intense)

| Direction  | Phrase Pattern                                |
|------------|-----------------------------------------------|
| Calm       | `slow, gentle`, `micro-movement`, `drift`, `breathe` |
| Intense    | `sharp, sudden`, `burst`, `impact`, `frozen mid-action` |
| Building   | `accelerating`, `tightening`, `rising`         |

**Always split into Valence + Arousal.** "Make it emotional" = failure. "Tense and held" = works. "Soft and drifting" = works.

## Motion Prompt Anti-Slop Lexicon (Negative Prompt Block)

Common AI-video tells. Include in NEGATIVE PROMPT section of every motion prompt unless your style explicitly wants them.

### Anatomy Tells

```text
no extra fingers, no fused fingers, no missing fingers,
no warped hands, no twisted wrists, no double-jointed limbs,
no asymmetric eyes, no melting facial features,
no plastic skin, no waxy skin, no airbrushed skin,
no perfect teeth, no uncanny valley smile,
no mannequin posture, no floating disconnected limbs
```

### Camera / Composition Tells

```text
no static grid, no split-screen, no contact sheet,
no picture-in-picture, no thumbnail mosaic,
no Dutch angle without purpose, no random whip pan,
no dissolving transitions between shots,
no zoom into pixels, no chromatic aberration
```

### Motion Tells

```text
no jitter loop, no rubber-band movement, no teleport cut,
no reverse playback tell, no frame interpolation smear,
no slow-mo unnecessary, no sudden speed change without intent,
no floating object that should fall, no cloth that doesn't react to wind
```

### Style Tells (when realism wanted)

```text
no anime, no cel shading, no painterly look,
no watercolor texture, no plastic CGI look,
no over-saturated neon, no HDR halation,
no instagram filter, no TikTok preset
```

### Style Tells (when anime wanted)

```text
no photoreal face, no deep shadow, no film grain,
no Western realism, no skin pore detail,
no sweat sheen, no subsurface scattering
```

## Cinematic Imperfect Realism Texture Pack

When the brief asks for "cinematic realism" or "looks real, not AI":

```text
film grain: subtle 35mm texture, not digital noise
lens: minor chromatic aberration at frame edges
lighting: motivated by practicals, not studio
color: muted palette, lifted blacks, no crushed contrast
sound: room tone + ambient, no studio reverb
actor: imperfect posture, asymmetric features, real skin texture
wardrobe: lived-in, not styled, slight wrinkles
environment: details not polished, dust, wear, asymmetry
```

## Continuity Lock Vocabulary

When multi-clip narrative, lock these terms across all motion prompts:

### Spatial Continuity
```text
room: [exact description of room]
screen left: [item] | screen right: [item] | screen center: [item]
window: behind character at 2 o'clock
door: behind camera, 12 o'clock from character's perspective
floor: wood plank, runs screen-left to screen-right
```

### Temporal Continuity
```text
time of day: locked to [golden hour / night / overcast noon]
weather: locked across clips
lighting: locked to source direction + color temperature
wardrobe state: locked to [description, no changes]
prop state: locked to [position, condition]
```

### Character State Continuity
```text
hair: [description] | face: [description] | posture: [description]
wardrobe: [description] | hands: [description]
carry-overs: [object from previous clip visible / not visible]
```
