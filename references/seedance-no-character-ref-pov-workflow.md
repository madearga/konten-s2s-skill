# Seedance/Dreamina No-Character-Reference POV Workflow

Use this when Seedance/Dreamina (or any Seedance-class UI) cannot accept human character reference images, or when face consistency would slow production.

## Core pivot

Do **not** fight face-lock. Redesign the film so it does not need a stable face.

Use:
- POV / cameraman-eye language
- hands, phones, shoes, cropped shoulders, silhouettes
- blurred faces, reflections, backs of heads, frosted glass
- many anonymous characters instead of one fixed protagonist
- recurring objects as continuity anchors: phone glow, corridor, group chat, door handle, report/help gesture

Avoid:
- character-reference dependency
- repeated full-face shots
- stable protagonist close-ups
- dashboard-heavy tech scenes unless the story truly needs them

## For cyberbullying PSA / competition videos

If the user wants focus on cyberbullying + victim, keep the narrative human-centered:
1. Fast hook: notification/comment avalanche, POV phone, crowd reaction.
2. Explainer: video is cut, captioned, shared, and judged.
3. POV perpetrator: one thumb, one send, moral hesitation.
4. POV bystander: sees harm, hesitates, silence as choice.
5. POV victim: hands/phone/breath/room, no face, no self-harm.
6. Human intervention: one person stops watching and goes for help.
7. Support: friend/teacher/parent presence, phone put down.
8. CTA: Laporkan. Temani. Dengarkan.

If contest theme mentions AI, AI can be the production method. Do not force AI/dashboard into the story if the user asks to focus on victim and cyberbullying.

## Safety guardrails

- No self-harm, no method, no blood, no body-on-floor imagery.
- No explicit readable slurs; represent hate as blurred lines, notification clusters, and reaction.
- No clear victim face unless user explicitly approves.
- Use environmental and behavioral impact: trembling hands, phone face-down, corridor isolation, door knock, chair scrape.

## Storyboard generation cadence

Default for Arga-style review: generate storyboards **one by one** for approval. Use parallel generation only after explicit approval (e.g. user says “paralel boleh/lanjut paralel”).

## Motion prompt structure

For each scene:
- GLOBAL STYLE LOCK: vertical 9:16, photorealistic Indonesian school PSA, POV/no fixed character, blurred/cropped faces, no logos.
- SUBJECT: one-sentence scene role.
- ACTION: panel-by-panel motion.
- CAMERA: handheld POV, macro/OTS/corridor geography.
- RHYTHM: hook/explainer/hesitation/slow/CTA.
- VOICEOVER: exact narration.
- AUDIO: diegetic only.
- NEGATIVE: no AI dashboard if not in story, no clear faces, no self-harm, no real app/school logos.

## Example scene 6 replacement

Instead of “AI dashboard detects risk”, use:

> A bystander sees the message “aku capek,” types “Kamu di mana? Aku ke sana,” gets no reply, runs to a teacher/counselor, and knocks on a door. The door handle begins to open.

This preserves public-safety action while keeping the story human, engaging, and character-reference-free.
